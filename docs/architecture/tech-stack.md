# Tech Stack

## 현재 기준
- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- Deployment: AWS EC2 + Docker Compose
- Reverse Proxy: Nginx
- Mock Server: FastAPI

## 운영 원칙
- README.md에는 기술스택 요약만 유지한다.
- 상세 기준은 이 문서를 우선 참조한다.
- 기술스택이 변경되면 README.md, AGENTS.md, tech-stack.md를 함께 확인한다.
- 배포 구조가 변경되면 Docker Compose 및 Nginx 구성과 함께 문서 동기화를 수행한다.
