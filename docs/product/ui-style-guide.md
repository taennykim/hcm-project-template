# UI Style Guide

## 방향
Simple HCM SaaS의 UI 방향은 중소기업 관리자용 업무 SaaS이다.
모바일 앱은 MVP 범위에서 제외한다.
관리자 중심 UX를 기준으로 한다.
HCM 전체 사이트처럼 보이되, MVP 범위는 REAL, REAL-LITE, MOCK, COMING_SOON 상태로 통제한다.

## 레이아웃 기준
- 좌측 사이드바
- 상단 헤더
- 중앙 업무 화면
- 카드형 요약
- 테이블 중심 화면

## 스타일 톤
- 밝은 배경
- 차분한 블루/그레이 계열
- 업무용 SaaS 느낌
- 큰 여백
- 명확한 primary button

## 피해야 할 방향
- 복잡한 ERP 느낌
- 과도한 애니메이션
- 모바일 앱 우선 설계
- 대기업 HR 시스템 수준의 복잡한 화면

## 핵심 화면 방향
- 대시보드: 이번 달 처리할 일 중심
- 직원관리: 목록과 등록/수정 폼 중심
- 근태관리: 일자별 입력과 월 집계 중심
- 급여관리: 생성 단계와 결과 확인 중심
